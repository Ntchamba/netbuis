# T121b — domaine Jitsi et recherche limitée (429)

## 1. Domaine Jitsi
- `JitsiAccess.isValidDomain` / `hasValidDomain` (call_session.dart) : même règle que dashboard `jitsi.ts` (nom d'hôte, port éventuel, pas d'IP, au moins un point, ni schéma, ni identifiants, ni chemin). Seule différence : `localhost` refusé (pas de mode « dev » côté mobile).
- Refus : `JitsiMeetService.join` renvoie faux sans appeler le SDK ; `CallController` n'appelle même pas `join` et passe à l'erreur `joinFailed` existante (« La liaison audio n'a pas pu s'établir »), session annulée. Le jeton n'est ni affiché ni journalisé.
- Tests : table valides/invalides (call_data_test.dart), flux d'appel avec domaine `10.0.0.1` (call_flow_test.dart).

## 2. Recherche 429 `throttled`
- Autorisation exceptionnelle (brief) pour features/search : suggestions_controller.dart, results_screen.dart, search_screen.dart.
- `isThrottledError` (code `throttled` ou HTTP 429). Recherche écrite et vocale (même contrôleur) : message `search.error.throttled` (FR+EN) à la place du message générique ; aucune relance automatique (« Réessayer » reste une action de l'utilisateur).
- Suggestions : message sous le champ ; aucune requête pendant l'attente (`Retry-After`, sinon 10 s).
- Tests : search_screen_test.dart (429 recherche sans relance, réseau simple garde le message générique, 429 suggestions).
