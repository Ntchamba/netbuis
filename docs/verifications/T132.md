## Décisions
1. La page existante « Appels » (statistiques) est conservée ; la liste des appels à l'équipe est une page distincte.
2. Flux SSE par `fetch` + lecture du flux (pas `EventSource`), jeton en en-tête ; 401 → `refreshAccessToken()` puis une reconnexion immédiate ; coupure/silence > 20 s → reconnexion avec délai croissant (1 s à 15 s, ou `retry:` du serveur) ; `closed` ou 403 → arrêt.
3. À chaque (re)connexion la liste des sonneries est vidée puis refaite avec le rejeu du serveur.
4. Domaine Jitsi validé (nom d'hôte seul) avant de charger `https://<domaine>/external_api.js`.
5. Les erreurs (« un collègue a déjà répondu »…) s'affichent par un message de la fenêtre d'appel et non par `useToast` (le layout est aussi rendu sans `ToastProvider` dans des tests existants).
6. Aucune dépendance npm ajoutée. Playwright n'est pas dans `package.json` (installé globalement) : le script `e2e/appel-entrant.mjs` le charge par `PLAYWRIGHT_MODULE` ou `playwright`.
