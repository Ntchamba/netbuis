# Vérification du dépôt avant travail par un agent cloud (2026-10-17)

Contrôle du dépôt `Ntchamba/netbuis` (commit `1b59dc7`, « premier lancement du devellopement ») et des fichiers du Projet Claude,
pour qu'un agent Claude Code dans le cloud puisse reprendre avec la méthode de l'orchestrateur et des neuf agents.

## Ce qui est cohérent

- La méthode est complète et se tient : `CLAUDE.md` → `docs/ORCHESTRATION.md` (boucle, brief, vérification, arrêts, reprise) → `docs/PROGRESS.md` (état) → `docs/BACKLOG.md` (T000–T125, critères « Terminé quand »).
- Les dix fichiers d'agents (`a1 a2 a3 b1 b2 b3 c1 c2 c3` + `verificateur`) existent, chacun avec son périmètre, sa méthode et ses interdits ; `c1` est bien marqué reporté.
- Architecture et décisions concordent partout : Flutter / Django 5.2 + DRF + PostgreSQL / React Vite ; appel direct `tel:` + `wa.me` ; numéro du commerçant remis seulement par `POST /api/calls/initiate/` ; paiements CamPay reportés (`CREDITS_ENABLED=False`).
- Le code correspond à `PROGRESS.md` : T006b (HMAC-SHA256, `OTP_TEST_MODE` retiré, plus de `netbuis:netbuis` dans le code) est bien présent.
- `docs/ORCHESTRATION.md` est identique au guide d'orchestration du Projet Claude.

## À faire par Jeff

1. **Changer le mot de passe PostgreSQL local** qui était dans `backend/.env` : il reste lisible dans l'historique du premier commit (dépôt privé, base locale, mais la règle du projet est qu'il ne sorte jamais du fichier).
2. **`.claude/settings.json` interdit encore `git push`.** En local c'est voulu ; dans le cloud, l'agent ne pourra pas sauvegarder son travail. Pour le mode cloud, remplacer la ligne `"Bash(git push:*)"` de `deny` par `"Bash(git push origin main:*)"` et `"Bash(git push --force:*)"`. (Changement de réglage de sécurité : laissé à ta décision.)
3. **Relire T006b** (zone 🔒, en attente depuis le 2026-10-11), sinon l'orchestrateur ne passe pas à T007.
4. Facultatif : pousser l'historique réel (`cd ~/NETBUIS/netbuis && git push origin etape-1/socle`) si tu veux garder les commits T000→T006b ; sinon la branche cloud repart de `main`.
